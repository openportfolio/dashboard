# 설치와 설정

## 필요한 것

- Node 24 이상 (`node:sqlite` 와 TypeScript 직접 실행을 쓴다)
- pnpm: `corepack enable` 하면 `package.json` 에 적힌 버전이 깔린다
- 토스증권 Open API 키 (둘러보기만 할 거면 없어도 된다 → [데모 모드](#데모-모드))

## 토스증권 Open API 키

[openapi.tossinvest.com](https://openapi.tossinvest.com) 에서 발급한다. 알아 둘 것:

- **발급 때 등록한 IP 에서만 호출된다.** 집 공인 IP 가 바뀌거나 다른 곳에서 켜면 `401 … ip-not-allowed` 가 난다.
- **키 하나에 유효한 토큰은 하나뿐이다.** 새로 발급하면 이전 토큰이 바로 끊긴다. 같은 키로 다른 프로그램을 같이 돌리면 서로 끊으니 키를 따로 쓴다.
- 대시보드는 조회만 한다. 주문 API 는 부르지 않는다.

처음 열면 연결 화면이 뜬다. Client ID · Secret 과 연락처 이메일(선택)을 넣으면 서버가 토스에 토큰과 계좌 목록을 요청해 확인하고, 맞을 때만 `server/data/portfolio.db` 에 저장한다. Secret 은 화면으로 다시 돌려주지 않는다.

- 연락처 이메일은 ETF 보유종목(SEC EDGAR)을 받을 때 밝히는 연락처다. 없으면 ETF 를 펼치지 못하고 묶음으로 보인다.
- 나중에 바꾸려면 오류 줄의 '키 다시 입력' 이나 `http://localhost:5280/?setup`.

화면 대신 `server/.env` 에 둘 수도 있다 (`server/.env.template` 참고). 있으면 화면에서 넣은 키보다 우선한다.

| 이름                 | 설명                                    |
| -------------------- | --------------------------------------- |
| `TOSS_CLIENT_ID`     | Open API 키                             |
| `TOSS_CLIENT_SECRET` |                                         |
| `SEC_USER_AGENT`     | SEC EDGAR 용 연락처. `이름 이메일` 형식 |

## 실행

```bash
pnpm install
pnpm dev        # → http://localhost:5280 (처음이면 연결 화면)
```

API 서버(:8000)와 웹(:5280)이 같이 뜬다. 서버 포트를 바꾸려면 셸에서 `PORT=8001 pnpm dev` (웹 프록시도 따라간다).

## 데모 모드

```bash
pnpm demo
```

키 없이 가짜 계좌로 모든 화면을 띄운다. 2023년 1월부터 미국 ETF · 주식 7개와 삼성전자를 매달 사 모은 계좌이고, 가격 · 배당 · 환율은 Yahoo Finance 실제 데이터다. 실시간 체결은 0.4초마다 지어낸다.

- 기록 DB 는 메모리에만 있어서 끄면 사라진다 (실제 `server/data/portfolio.db` 는 건드리지 않는다).
- 가짜 계좌 구성은 `server/src/integrations/demo.ts` 의 `PLAN` 에서 바꾼다.

## 데스크톱 앱

```bash
pnpm app        # 웹을 빌드하고 Electron 창으로 연다
pnpm app:dist   # 설치 파일 (clients/apps/desktop/release: macOS dmg · Windows exe · Linux AppImage)
```

브라우저 대신 앱 창으로 쓴다. 서버도 앱 안에서 돌아서 따로 켤 것이 없고, 키는 연결 화면에서 넣는다 (`server/.env` 는 읽지 않는다).

- 토스 Secret 은 OS 키체인(macOS 키체인 · Windows DPAPI)으로 암호화해 저장한다. 키체인이 바뀌어 풀 수 없으면 연결 화면이 다시 뜬다.
- 기록 · 전략 · 키는 OS 사용자 폴더에 둔다. macOS `~/Library/Application Support/OpenPortfolio`, Windows `%APPDATA%\OpenPortfolio`.
- 한 번에 하나만 뜬다. 같은 키로 `pnpm dev` 와 앱을 같이 켜면 토큰을 서로 끊는다.
- 지금 설치 파일은 서명하지 않았다. 직접 빌드한 앱은 그냥 열리지만, 받은 파일은 macOS 에서 '확인되지 않은 개발자' 경고가 뜬다 (Finder 에서 오른쪽 클릭 → 열기).

## 데이터

`server/data/portfolio.db` (gitignore, 폴더 권한 0700) 에 쌓인다.

| 무엇             | 언제 쌓이나                                       | 지우면                      |
| ---------------- | ------------------------------------------------- | --------------------------- |
| 거래일별 총자산  | 대시보드를 켠 날 마지막 값 (08:00 KST 에 날 넘김) | 되살릴 수 없다              |
| 오늘 1분 흐름    | 대시보드를 켠 동안                                | 되살릴 수 없다              |
| 전략             | 고칠 때마다                                       | 되살릴 수 없다              |
| 토스 키 · 연락처 | 연결 화면에서 저장할 때                           | 연결 화면에서 다시 넣는다   |
| 체결 내역        | 거래 탭을 열 때 새 주문만                         | 다음에 토스에서 다시 받는다 |

## 문제 해결

화면 위 빨간 줄이나 서버 로그에 뜨는 메시지 기준.

| 메시지                                | 원인 · 해결                                                                                                                                           |
| ------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------- |
| `토스 Open API 키가 없습니다`         | 키가 없다. 연결 화면(`/?setup`)에서 넣는다                                                                                                            |
| `401 … ip-not-allowed`                | 등록하지 않은 IP 에서 호출했다. 토스 Open API 에 지금 공인 IP 를 등록한다                                                                             |
| `토큰 발급 실패 …`                    | 키가 틀렸거나 폐기됐다                                                                                                                                |
| 같은 키를 쓰는 다른 프로그램이 끊긴다 | 토큰이 키당 하나라 서로 끊는다. 키를 나눠 쓴다                                                                                                        |
| `토스증권 종합매매 계좌가 없습니다`   | Open API 는 종합매매 계좌만 보여 준다                                                                                                                 |
| 서버 로그 `[분류] … 실패`             | 섹터 분류용 공개 데이터(SSGA · SEC)를 못 받았다. 잔고는 그대로 보이고 해당 종목만 '미분류' · ETF 묶음으로 보인다. SEC 는 `SEC_USER_AGENT` 를 확인한다 |
| `Yahoo …: HTTP 429`                   | Yahoo 가 잠시 막았다. 몇 분 뒤 다시 연다. 배당을 못 받은 종목은 배당 없이 계산하고 각주에 적는다                                                      |
| 국내 종목이 '미분류'                  | 국내 종목은 자동 분류 출처가 없다. `server/src/sector/classification.ts` 의 `STOCK_SECTOR` 에 더한다                                                  |
